# BridgeAI（桥智）

**默认面向全球英文市场**（官网、文档、控制台与开发者支持以英文为主）的 **AI 模型路由与治理层**：在统一接口下连接多家模型供应商，提供 **失败回退**、**成本护栏**与**可观测性**；并以 **中文场景路由**等能力服务华语用户与中文业务（中文名 **桥智** 可用于华语传播与品牌延伸）。
